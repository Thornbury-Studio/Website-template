# Hub UI critique

## Attitude

Be honest. If the design is average, weak, cluttered, or generic AI-looking, say so.
Do not soften with empty praise. Prefer one strong composition over stacked effects.

## Score every pass (1–5)

1. **Brand first** — Could this first viewport belong to another brand after removing nav?
2. **Hero budget** — Brand + one line + one CTA group + one dominant visual. No chip soup.
3. **One job per section** — Extra strips, tickers, and card clusters get cut unless they earn space.
4. **Effects budget** — Max 2–3 intentional motions. Effects never replace hierarchy.
5. **Clickability** — Primary paths obvious; cards look distinct, not cloned mini-UIs.

## Hard rejects

- Purple-on-white / indigo glow defaults
- Warm cream + terracotta “AI brochure” look
- Dense broadsheet / newspaper columns
- Cards used as decoration (no interaction need)
- Inset hero media cards when a full-bleed plane is better
- Floating badges/stickers on hero media

## Direction for this product

- Hub: quiet mint studio commons — sharp type, soft atmosphere, few sections
- Showcase: Awwwards-style gallery — uniform thumbs, clean metadata, detail overlay
- Keep hub and showcase related, not two random products

## Output format when reviewing

```
Verdict: <strong / ok / weak>
Scores: brand _/5 · hero _/5 · sections _/5 · motion _/5 · click _/5
What’s working: …
What’s shit / weak: …
Do next (max 3): …
```
